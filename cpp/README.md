## 📦 Automatic Build (No Manual Compilation Needed!)

The repository includes a **GitHub Actions workflow** that compiles the triggerbot automatically. You don't need to manually run g++ or deal with compiler settings.

### How to build:
1. Go to the **Actions** tab on GitHub
2. Click **"Build TriggerBot"** workflow
3. Click the **Run workflow** button (▶️)
4. Wait ~2-3 minutes
5. Download `triggerbot.exe` from the artifact

### Or push a change:
```bash
git commit --allow-empty -m "trigger build"
git push origin main
```

The workflow will auto-run and produce `triggerbot.exe`.

## 🛠️ How It Works

### Main Workflow (`src/main.cpp`)
1. Reads configuration from `config.cfg`
2. Loads memory offsets from `cs2-dumper-main/output/`
3. Attaches to `cs2.exe` process
4. Scans entity list for valid targets
5. Fires trigger when crosshairs are over enemies
6. Handles GUI input (F1-F9 shortcuts)

### Memory Offsets (`src/offsets.h`)
Contains hardcoded offsets for Source2 classes:
- `dwEntityList` - Entity list pointer
- `dwLocalPlayerPawn` - Local player pointer
- `dwViewMatrix` - View/projection matrix
- `m_iTeamNum` - Team number
- `m_iHealth` - Health status
- `m_fFlags` - Player flags (alive, grounded, etc.)
- Bone indices (Head, Chest, Stomach, Pelvis)

**⚠️ CRITICAL: Offsets must be updated when CS2 updates!** The `cs2-dumper-main/` folder is excluded from this repo. Get fresh offsets from [cs2-dumper](https://github.com/frk1/cs2-dumper).

### Memory Reading (`src/memory.h`)
Uses `ReadProcessMemory` to:
- Attach to `cs2.exe` by process name
- Find `client.dll` module base address
- Read entity pointers from the entity list
- Traverse pointer chains to player data

### World-to-Screen (`src/w2s.h`)
Converts 3D world coordinates to 2D screen coordinates using the view matrix. Returns valid position when `sw_val > 0.001` (entity is on screen).

### Overlay (`src/overlay.h`)
Renders a transparent overlay covering the entire screen:
- ESP boxes, health bars, snaplines
- Crosshair indicators
- Configurable colors and styles

## 🔧 Building from Source (Local)

### Prerequisites
- Windows OS
- MinGW (g++) compiler
- Windows API headers (included with MinGW)

### Using GitHub Actions (Recommended)
1. Fork this repository
2. Push to `main` branch
3. Workflow auto-builds `triggerbot.exe`
4. Download artifact from Actions tab

### Local Build
```bash
g++ -O2 -std=c++17 -o triggerbot.exe src/main.cpp -lgdi32 -luser32 -lkernel32 -lcomctl32 -static
```
Or run: `build.bat`

### Output
- `triggerbot.exe` - The compiled triggerbot executable
- Place alongside `cs2.exe` with `cs2-dumper-main/` nearby

## 🚀 Getting Started

1. **Install CS2** and launch the game
2. **Update offsets** from cs2-dumper to match your game version
3. **Build the project** using GitHub Actions or locally with `build.bat`
4. **Run `triggerbot.exe`** while CS2 is running
5. **Configure** using F1-F9 keys in-game

**Remember:** The most important part is keeping offsets updated. Without current offsets, the triggerbot will not function correctly.
