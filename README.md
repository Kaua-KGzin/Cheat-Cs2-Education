# CS2 TriggerBot - C++ Implementation

## Overview
This repository contains a C++-based Counter-Strike 2 (CS2) triggerbot source code. The project reads memory from `cs2.exe`, detects enemy entities, and automatically fires when crosshairs are over valid targets.

**Important: This project is for educational purposes only. Use at your own risk.**

## ⚠️ Critical Setup Requirements

### Offsets Must Be Updated
This triggerbot relies on memory offsets to locate game entities and player data. **CS2 updates frequently, breaking offsets.** To make this work:

1. Obtain fresh offsets from a trusted CS2 dumper (e.g., [cs2-dumper](https://github.com/frk1/cs2-dumper))
2. Replace the files inside `cs2-dumper-main/output/` with the latest dumper output
3. Ensure `offsets.h` reflects the current game version

**The `cs2-dumper-main/` folder is intentionally excluded from this repository** (see `.gitignore`). You must maintain offsets separately.

## Key Source Files Explained

### `src/main.cpp`
The main loop that:
- Reads config from `config.cfg`
- Loads offsets from `cs2-dumper-main/output/`
- Attaches to `cs2.exe` process
- Scans entities and triggers shots
- Handles GUI input (F1-F9 shortcuts)

### `src/offsets.h`
Contains hardcoded memory offsets for Source2 classes. **Must be updated** whenever CS2 updates. Currently includes:
- `dwEntityList` - Entity list pointer
- `dwLocalPlayerPawn` - Local player pointer
- `dwViewMatrix` - View/projection matrix
- `m_iTeamNum` - Team number offset
- `m_iHealth` - Health offset
- `m_fFlags` - Player flags (alive, grounded, etc.)
- Bone indices (Head, Chest, Stomach, Pelvis)

### `src/memory.h`
Process memory reader using `ReadProcessMemory`. Handles:
- Process attachment by name (`cs2.exe`)
- Module finding (`client.dll`)
- Reading memory at dynamic pointers
- Entity list traversal

### `src/gui.h`
Windows GUI with:
- 14 control IDs (buttons, sliders)
- 21 color settings for rendering
- Preset modes: "legit", "semi", "rage"
- Config save/load functionality

### `src/aimbot.h`
Aimbot logic with:
- FOV-based target selection
- Smooth aiming with configurable sensitivity
- Deadzone filtering
- Stick radius limiting

### `src/w2s.h`
World-to-screen conversion using the view matrix. Returns screen coordinates if the entity is visible (sw_val > 0.001).

### `src/trigger.h`
Trigger bot functionality that:
- Checks if crosshairs are over valid targets
- Applies trigger delay
- Filters by bone and distance

### `src/overlay.h`
DirectX/GDI overlay for rendering:
- Transparent layered window covering entire screen
- Drawing: boxes, lines, text, health bars, crosshairs, snaplines

## Building from Source

### Prerequisites
- Windows OS
- MinGW (g++) compiler
- Windows API headers (included with MinGW)

### Using GitHub Actions (Recommended)
1. Fork this repository
2. Push to `main` branch
3. The workflow automatically builds `triggerbot.exe`
4. Download the artifact from the Actions tab

### Local Build
1. Open PowerShell or Command Prompt in the `cpp/` directory
2. Run: `g++ -O2 -std=c++17 -o triggerbot.exe src/main.cpp -lgdi32 -luser32 -lkernel32 -lcomctl32 -static`
3. Or run `build.bat` which executes the same command

### Output
- `triggerbot.exe` - The compiled triggerbot executable
- Place `triggerbot.exe` alongside `cs2.exe` with the `cs2-dumper-main/` folder nearby

## Configuration

### `config.cfg`
Default settings included:
- ESP, trigger, aimbot, anti-recoil toggles
- Aim sensitivity (4.5), smooth (0.35), FOV (350)
- Deadzone (10), stick radius (400)
- Trigger delay (5ms), max distance (2000)
- Bone selection (0=Head), recoil strength (50)

**Note:** `config.cfg` is excluded from the repository via `.gitignore`. Copy it from the build output if needed, or create your own.
